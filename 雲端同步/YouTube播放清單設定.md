# YouTube 播放清單設定

教材庫可以貼 YouTube 播放清單的分享網址，網頁會列出清單裡的每支影片，點一下就在網站裡播放。

## 啟用「讀取播放清單影片」（只需做一次）

1. 打開原本的 Google Apps Script 專案，把這個資料夾最新版 `Code.gs` 全部貼進「程式碼.gs」，按儲存。
2. 選「部署 → 管理部署作業 → 鉛筆圖示 → 版本：新版本 → 部署」。這樣會沿用原本的部署網址。
3. 回到網頁按 Ctrl+F5 重新整理。

不需要新的權限，也不需要 YouTube API 金鑰（沿用原本的 `script.external_request`）。

## 使用方式

1. 教材庫 →「＋ 新增連結」→ 貼上播放清單分享網址，例如 `https://youtube.com/playlist?list=...`。名稱與「影片」類型會自動帶入。
2. 儲存後按「▶ 播放清單」：左邊是播放器，右邊是清單裡的每支影片，點一下就切換。
3. 第一次開啟會自動讀取清單（約幾秒到幾十秒），之後會記住；清單有新增影片時按「重新讀取」。
4. 想讓每支影片都能單獨搜尋、收藏，按「每支影片各存成教材」。已在教材庫的影片會略過。

## 注意

- 清單必須是「公開」或「不公開」（有連結就能看）；「私人」清單讀不到。
- 一次最多讀 500 支影片。若 YouTube 改版導致讀不到，會改用 YouTube 的訂閱來源，只能列出最新 15 支。
- 有些影片的作者禁止嵌入，播放器會顯示錯誤，請改按「在 YouTube 開啟」。
