# 啟用自動國定假日

1. 用目前雲端同步的同一個 Google Apps Script 專案開啟編輯器。
2. 將本資料夾的 `Code.gs` 完整內容替換原檔並儲存。
3. 進入「專案設定」，勾選「在編輯器中顯示 appsscript.json 資訊清單檔案」。回到編輯器，把本資料夾的 `appsscript.json` 內容貼入該檔案。若原專案還使用其他服務，保留原有欄位與其他 scopes，新增 `https://www.googleapis.com/auth/script.external_request` 即可；不要重複建立同名資訊清單檔案。
4. 在編輯器上方函式下拉選單選擇 `authorizeServices`，按「執行」，用部署帳號完成 Google 授權。執行紀錄顯示「授權完成」後，到「部署 → 管理部署 → 編輯 → 新版本 → 部署」。保留原網址與原本的存取權限，確認執行身分仍是部署帳號。新增功能會以 UrlFetchApp 讀取政府公開資料，不讀取私人相簿或其他帳號資料。
5. 網頁重新整理後，進入「行事曆」，按「更新官方假日」。

開啟網頁或切回網頁時，每日最多自動檢查一次（手動更新不受此限制）。資料讀自新北市政府人事處的政府行政機關辦公日曆表，涵蓋今年及已公布的明年度；GAS 會快取 6 小時。

來源：https://data.ntpc.gov.tw/datasets/308dcd75-6434-45bc-a95f-584da4fed251

一般週末不匯入為國定假日；不自動將政府補行上班日當成課輔班補課日。班級的補課、自訂放假保留。若學校行事曆不同，請另外設定班級補課或停課。

連線失敗時保留原資料。網頁關閉時不會執行更新，下次開啟會再檢查。自動資料以外的行事曆紀錄不會被清除；手動編輯自動假日後會改標為自訂來源。
