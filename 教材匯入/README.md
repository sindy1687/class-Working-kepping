# 教材匯入（精簡版）

從 `教材匯入`（195 MB 工作檔）精簡而來，只保留最終成果與可重現匯入的腳本。

## 內容

- `教材庫-最終.json` — 最終教材庫，7,419 筆 Google Drive 教材連結（已移除空白欄位與重複路徑，內容與「教材庫-加入每週大事.json」等價）
- `scripts/` — 各階段匯入用的 Node 腳本（整理、分學段、細分類、合併、修復、加入各科）
- `參考資料/` — 來源檔案清單、雲端檔案清單、每週大事連結、合併報告、待核對重複群組

## 被精簡掉的檔案

原資料夾其餘檔案為一次性工作檔，已不需要：

- `*.base64` — 各階段從雲端讀回的快照（31 個，約 120 MB，內容多為彼此重複）
- `*前.json`、`*前備份.json` — 各步驟執行前的備份
- `教材庫-*.json`（除最終版）— 匯入過程的中間狀態（每個都是完整庫的快照）

原始檔案仍在 `教材匯入/` 資料夾（OneDrive 有同步），需要時可取回。
